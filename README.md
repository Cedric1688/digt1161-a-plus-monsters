# A+ Monsters

A DIGT1161 team project for short daily practice reviewing AI-written Python code.

## Current stage

Proposal and repository setup. No runnable application, deployed service, completed interview, or user-test result is claimed by this repository.

The proposed MVP uses fictional test accounts, three-question daily challenges, answer explanations, saved progress, and a study-group streak. Placement quizzes, adaptive difficulty, public registration, additional languages, PWA installation, and code execution are outside the MVP.

## Workflow

Use `main` and a feature branch for each task. Every PR requires at least one peer review before merge; no self-merge. Track work as Backlog → In progress → In review → Done. Limit in-progress work to one card per person and review work to three cards for the team.

## Preview the documentation

Install the documentation dependency in an isolated environment, then run `mkdocs serve`. Publish the `docs` site to GitHub Pages after the repository owner and Pages settings have been confirmed.

The repository does not include an implementation yet. The course's runnable-artifact requirement applies to the delivered product, not a claim that this setup is already the final product.
